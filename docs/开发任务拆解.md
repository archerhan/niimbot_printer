# 精臣 B1 标签自动打印 App — 开发任务拆解

> 对应文档：PRD.md ｜ 平台：Android 12+ ｜ 框架：Flutter

## 阶段总览

| 阶段 | 名称 | 目标 | 依赖 |
| :-- | :-- | :-- | :-- |
| P0 | 项目脚手架 | 可编译运行的 Flutter 工程 | 无 |
| P1 | 打印内核 Spike | 真机连上 B1 并打出一张测试标签，标定坐标 | P0 |
| P2 | 数据层 | 设置持久化 + 历史数据库 | P0 |
| P3 | 业务核心 | 拼接 / 扫码 / 预览 / 打印 / 跳号 / 连续 / 重打 | P1, P2 |
| P4 | 界面 | 主界面 / 预览 / 设置 / 历史 | P2, P3 |
| P5 | 连接与权限 | 自动连接 / 重连 / 运行时权限 | P1 |
| P6 | 打包交付 | 签名密钥 + release APK + 文档 | P4, P5 |
| P7 | CI/CD（后续） | GitHub Actions 自动打包 | P6 |

## P0 项目脚手架

- [ ] P0-1 用 `flutter create` 生成工程（org 名、包名待定，建议 `com.xxx.printer`）。
- [ ] P0-2 在 `pubspec.yaml` 加入依赖：`niim_blue_flutter: ^1.0.1`、`mobile_scanner: ^7.4.2`、`shared_preferences`、`sqflite`、`path`、`permission_handler`、`device_info_plus`。
- [ ] P0-3 配置 `AndroidManifest.xml`：蓝牙、蓝牙扫描、蓝牙连接、定位、相机权限。
- [ ] P0-4 配置 `build.gradle`：`minSdk 21`、`compileSdk/targetSdk` 设为 34/35。
- [ ] P0-5 建立目录结构：`lib/{screens,widgets,services,models,providers,utils}`。
- [ ] P0-6 配置应用名、图标、主题（Material 3）。

## P1 打印内核 Spike（最高优先级，先跑通再往下）

- [ ] P1-1 实现 `PrinterService`：`listDevices` → `setDevice` → `connect`，暴露连接状态。
- [ ] P1-2 实现最小打印：`PrintPage(384,240)` 画一个二维码 + 三行文字并打印。
- [ ] P1-3 打印前处理：`stopHeartbeat` / `packetIntervalMs=0`；成功后 `startHeartbeat`。
- [ ] P1-4 验证 `LabelType.withGaps` 打印后停在标签间隙。
- [ ] P1-5 真机标定：二维码位置/大小、三行文字 x/y/字号，记录一组可用默认坐标。
- [ ] P1-6 记录浓度（density）与打印质量关系，确认默认值。
- [ ] P1-7 输出《坐标标定记录》，回填 PRD 第 3.2 节默认值。

> 说明：本机暂无打印机，P1-4~P1-7 需在有 B1 的机器上执行。代码可先按预设值写好。

## P3 业务核心

- [ ] P3-1 `CodeGenerator`：拼接 `productCode` 与 `qrContent`（PRD 3.1），含左补零、超 9999 抛错。

- [ ] P3-3 重复配件码检测：查询历史 → 返回「沿用旧编号 / 生成新编号」选项。
- [ ] P3-4 跳号检测：`待打印序号 != 上次成功序号 + 1` 时触发警告（含「继续跳号打印」）。

- [ ] P3-6 打印执行封装：成功 → 序号+1 + 写历史成功；失败 → 写历史失败，序号不变。

- [ ] P3-8 重打：复用历史 `qrContent`，不递增序号，新增带「重打」标记记录并关联原记录。

## 关键风险与注意事项

1. **P1 是硬门槛**：没有真机（B1）无法标定坐标与验证打印，P3 之后的功能无法验收。建议尽快准备一台 B1。
2. **成功判定**：以 `waitForFinished()` 无异常作为「打印成功」；BLE 中途断连可能造成「实际已打印但判定失败」，需允许用户手动修正历史状态（后续可加）。
3. **序号安全**：单设备单线程操作即可；打印成功回调与递增之间建议加锁，避免并发重复。
4. **签名字段**：release 签名密钥请妥善保管，丢失将无法覆盖升级已安装的 App。
5. **标签纸**：必须使用 B1 兼容的 RFID 标签纸。
