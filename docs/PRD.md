# 精臣 B1 标签自动打印 App — 产品需求文档（PRD）

> 版本：v1.0 ｜ 日期：2026-10-09 ｜ 平台：Android（12+）

## 1. 背景与目标

公司现有精臣 B1 蓝牙标签打印机一台。操作员需为每件配件打印一张标签，标签上包含产品编号（自增）与配件编号（扫码获得）。

现用「精臣云打印」App 无法把扫码结果注入模板，产品编号只能手动输入或从 Excel 导入，效率低且易错。目标是用一个自研 Android App 实现「扫配件码 → 预览确认 → 蓝牙打印」的一键式流程。

## 2. 术语

| 术语 | 说明 | 示例 |
| :-- | :-- | :-- |
| 配件编号 | 操作员扫配件二维码得到的原始字符串 | `MDE62564302CDFL9D` |
| 前缀 A/B/C | 产品编号的三个可配置分段 | `ADM32672805` / `CTX` / `6O6` |
| 序号 | 自增的 4 位数字，左补零 | `0005` |
| 产品编号 | A+B+C+序号 拼接 | `ADM32672805CTX6O60005` |
| 二维码内容 | 标签上生成的完整字符串 | `!ADM32672805CTX6O60005#MDE:MDE62564302CDFL9D@RESULT:OK` |

## 3. 核心数据规则

### 3.1 号拼接

```
productCode = prefixA + prefixB + prefixC + serial.padLeft(4, '0')
qrContent   = '!' + productCode + '#MDE:' + accessoryCode + '@RESULT:OK'
```

示例：

```
productCode = 'ADM32672805' + 'CTX' + '6O6' + '0005' = 'ADM32672805CTX6O60005'
qrContent   = '!ADM32672805CTX6O60005#MDE:MDE62564302CDFL9D@RESULT:OK'
```

- `!`、`#MDE:`、`@RESULT:OK` 均为固定字符串。
- 配件编号直接取扫码原文，不做二次解析（扫码原文即配件编号）。

### 3.2 标签版式（初始预设，坐标可调）

标签物理尺寸约 48mm × 30mm，像素预设 **384 × 240**（B1 打印头 384 点，203 dpi）。

- 左侧二维码（约 140×140 px，内容为 `qrContent`）。
- 右侧三行左对齐文字：
  - 第 1 行：前缀 A（`ADM32672805`）
  - 第 2 行：前缀 B（`CTX`）
  - 第 3 行：前缀 C + `-` + 序号（`6O6-0005`）
- 二维码内容与三行文字之外，标签上不打印其它元素（不打印配件编号文字、日期、logo）。

> 坐标（x/y/字号）在「设置」中可调，用于现场微调；实机标定后再固化默认值。

## 4. 功能需求

### 4.1 扫码（FR-SCAN）

- FR-SCAN-1：主界面提供「扫描配件码」入口，调用相机扫描二维码。
- FR-SCAN-2：扫码结果原文即配件编号，显示给用户确认。
- FR-SCAN-3：重复扫码同一配件编号时，弹出选择：
  - 「沿用之前的产品编号」：查找历史中该配件编号最近一次使用的产品编号并复用。
  - 「生成新编号」：按当前序号生成新的产品编号。

### 4.2 编号生成（FR-CODE）

- FR-CODE-1：前缀 A/B/C 可在设置中修改，默认值为 `ADM32672805` / `CTX` / `6O6`。
- FR-CODE-2：修改后本地持久化，下次启动读取。
- FR-CODE-3：修改任一分段前缀时，弹出二次确认，确认后将序号重置为 `0001`。
- FR-CODE-4：序号默认 4 位、左补零，起始值 `0001`。
- FR-CODE-5：序号超过 `9999` 时报错并阻止打印，提示用户处理。

### 4.3 序号管理（FR-SERIAL）

- FR-SERIAL-1：序号仅在**打印成功回调之后**才递增（`waitForFinished` 成功）。
- FR-SERIAL-2：打印失败不递增，序号可被下一次成功打印复用。
- FR-SERIAL-3：设置中提供「手动修正序号」入口，需二次确认。
- FR-SERIAL-4：跳号警告——当待打印序号 ≠ 上次成功打印序号 + 1 时（无论何种原因），弹警告对话框，提供「继续跳号打印」按钮，由用户决定是否继续。

### 4.4 打印预览与打印（FR-PRINT）

- FR-PRINT-1：常规模式——扫码后生成 `qrContent` 与标签排版，弹出打印预览（PNG），用户点「打印」后才发送打印。
- FR-PRINT-2：预览取消不消耗序号、不写历史。
- FR-PRINT-3：打印前强制检查连接状态；未连接则提示并尝试重连。
- FR-PRINT-4：一次打印任务只打一张标签，打完停在标签间隙（`LabelType.withGaps`）。
- FR-PRINT-5：打印流程：`stopHeartbeat` → `packetIntervalMs=0` → `createPrintTask` → `printInit` → `printPage` → `waitForFinished` → `startHeartbeat`。
- FR-PRINT-6：打印成功后：序号 +1、写入历史（状态成功）。
- FR-PRINT-7：打印失败：写入历史（状态失败），序号不递增，提示用户。

### 4.5 连续模式（FR-CONT）

- FR-CONT-1：设置中提供「连续模式」开关，默认关闭。
- FR-CONT-2：开启后，扫到配件码直接打印，跳过预览确认。
- FR-CONT-3：连续模式中若一次打印失败或断连，暂停连续流程并弹出提示，由用户决定是否继续。

### 4.6 打印历史与重打（FR-HIST）

- FR-HIST-1：用 `sqflite` 持久化打印历史。
- FR-HIST-2：记录字段见第 6 节数据模型。
- FR-HIST-3：历史列表显示：时间、产品编号、配件编号、序号、状态（成功/失败）、是否重打。
- FR-HIST-4：支持对历史记录执行「重打」——复用记录中的原始 `qrContent` 重新打印。
  - 重打**不递增序号**（同一张标签）。
  - 重打会**新增一条带「重打」标记的记录**，并关联原记录。

### 4.7 打印机连接（FR-CONN）

- FR-CONN-1：记录并持久化上次连接的设备 ID。
- FR-CONN-2：启动时自动连接上次设备，自动重连重试若干次。
- FR-CONN-3：重试仍失败则提示用户，并提供手动扫描/选择设备入口。
- FR-CONN-4：显示当前连接状态（已连接设备名 / 未连接 / 连接中）。
- FR-CONN-5：注册断连回调（`setOnDisconnect`），断连时更新状态并可自动重连。

### 4.8 设置（FR-SET）

- FR-SET-1：前缀 A/B/C 配置（含默认值）。
- FR-SET-2：手动修正序号。
- FR-SET-3：连续模式开关。
- FR-SET-4：标签排版微调：x 偏移、y 偏移、字号、打印浓度（density 1–5）。
- FR-SET-5：设备管理（当前设备 / 重新连接 / 切换设备）。

### 4.9 权限（FR-PERM）

- FR-PERM-1：Android 12+ 运行时申请 `BLUETOOTH_SCAN`、`BLUETOOTH_CONNECT`、`CAMERA`。
- FR-PERM-2：权限被拒绝时给出引导提示，提供跳转系统设置的入口。

## 5. 状态与异常处理

| 场景 | 处理 |
| :-- | :-- |
| 打印中途断连 | 历史标失败，序号不递增，提示用户；连续模式暂停 |
| 标签纸用完 | 打印任务返回失败，按打印失败处理并提示 |
| 扫码失败/无法识别 | 提示重新扫描，不进入打印流程 |
| 权限被拒绝 | 引导提示 + 跳转设置 |
| 序号超 9999 | 阻止打印，报错提示 |
| 序号跳号 | 弹警告，提供「继续跳号打印」按钮 |
| 蓝牙未开启 | 提示开启蓝牙 |

## 6. 数据模型

### 6.1 设置（shared_preferences）

| Key | 类型 | 默认 | 说明 |
| :-- | :-- | :-- | :-- |
| `prefixA` | String | `ADM32672805` | 前缀 A |
| `prefixB` | String | `CTX` | 前缀 B |
| `prefixC` | String | `6O6` | 前缀 C |
| `serialNumber` | int | 1 | 当前序号 |
| `serialLength` | int | 4 | 序号位数 |
| `continuousMode` | bool | false | 连续模式 |
| `offsetX` / `offsetY` | int | 0 | 排版偏移 |
| `fontSize` | double | 22 | 文字字号 |
| `density` | int | 3 | 打印浓度 |
| `lastDeviceId` | String | 空 | 上次设备 ID |
| `lastDeviceName` | String | 空 | 上次设备名 |

### 6.2 打印历史（sqflite，表 `print_history`）

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | INTEGER PK AUTOINCREMENT | 主键 |
| `createdAt` | INTEGER | 时间戳（毫秒） |
| `productCode` | TEXT | 产品编号 |
| `accessoryCode` | TEXT | 配件编号 |
| `serial` | INTEGER | 序号 |
| `qrContent` | TEXT | 二维码原文 |
| `status` | INTEGER | 0=失败，1=成功 |
| `isReprint` | INTEGER | 是否重打 |
| `originalId` | INTEGER | 重打时关联的原记录 ID |
| `deviceId` | TEXT | 打印设备 ID |

## 7. 非功能需求

- 全程离线运行，不依赖网络。
- 单设备（一台手机）使用，序号与历史存本地。
- 界面语言：简体中文。
- 换手机时提示用户「序号与历史不会自动迁移」，导入/导出后续版本再做。

## 8. 待确认与假设

1. **标签像素尺寸** `384 × 240` 为依据照片比例的估算值，需实机标定后固化。
2. **`#MDE:`** 中的 `MDE` 按固定常量处理（配件编号恰好也以 MDE 开头，若两者无关联则维持固定串）。
3. **序号上限** 9999，触发后仅报错，不做自动进位。
4. **重复配件码判定** 依据历史中是否已存在相同 `accessoryCode`。
5. **重打不占新号**，仅新增带标记的历史记录。
6. 时间显示使用设备本地时间。
