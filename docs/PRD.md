# 标签助手 — 产品需求文档（PRD）

> 版本：v1.1 ｜ 日期：2026-10-13 ｜ 平台：Android（12+）

## 1. 背景与目标

公司现有精臣蓝牙标签打印机（B1 / Z401）。操作员需为每件配件打印一张标签，标签上包含产品编号（自增）与配件编号（扫码获得）。

现用「精臣云打印」App 无法把扫码结果注入模板，产品编号只能手动输入或从 Excel 导入，效率低且易错。目标是用一个自研 Android App 实现「扫配件码 → 预览确认 → 蓝牙打印」的一键式流程。

由于存在多个产品系列、各系列前缀差异较大，App 需支持预置多套产品系列并快速切换。

## 2. 术语

| 术语 | 说明 | 示例 |
| :-- | :-- | :-- |
| 配件编号 | 操作员扫配件二维码得到的原始字符串 | `MDE62564302CDFL9D` |
| 产品系列 | 一套产品编号配置：产品名称 + 前缀 A/B/C + 该系列自己的序号 | 「ADM 系列」 |
| 前缀 A/B/C | 产品编号的三个可配置分段（属于某个产品系列） | `ADM32672805` / `CTX` / `6O6` |
| 序号 | 自增的 4 位数字，左补零 | `0005` |
| 产品编号 | A+B+C+序号 拼接 | `ADM32672805CTX6O60005` |
| 二维码内容 | 标签上生成的完整字符串 | `!ADM32672805CTX6O60005#MDE:MDE62564302CDFL9D@RESULT:OK` |

## 3. 核心数据规则

### 3.1 号拼接

```
productCode = prefixA + prefixB + prefixC + serial.padLeft(4, '0')
qrContent   = '!' + productCode + '#MDE:' + accessoryCode + '@RESULT:OK'
```

示例：

```
productCode = 'ADM32672805' + 'CTX' + '6O6' + '0005' = 'ADM32672805CTX6O60005'
qrContent   = '!ADM32672805CTX6O60005#MDE:MDE62564302CDFL9D@RESULT:OK'
```

- `!`、`#MDE:`、`@RESULT:OK` 均为固定字符串。
- 配件编号直接取扫码原文，不做二次解析（扫码原文即配件编号）。
- 前缀 A/B/C 与序号取自**当前产品系列**（见 FR-SERIES），序号按系列各自维护。

### 3.2 标签版式（初始预设，坐标可调）

标签尺寸以**毫米**配置（默认 40 × 20 mm），按打印机 DPI 换算为像素：
像素 = 毫米 × DPI ÷ 25.4。例如 40 × 20 mm @ 300 dpi = **472 × 236** 像素。
DPI 在连接打印机后依据型号自动识别（B1 = 203，Z401 = 300）。

- 左侧二维码（约 140×140 px，内容为 `qrContent`）。
- 右侧三行左对齐文字：
  - 第 1 行：前缀 A（`ADM32672805`）
  - 第 2 行：前缀 B（`CTX`）
  - 第 3 行：前缀 C + `-` + 序号（`6O6-0005`）
- 二维码内容与三行文字之外，标签上不打印其它元素（不打印配件编号文字、日期、logo）。
- 前缀允许留空：对应行保留为空行以维持三行版式；前缀 C 为空时第 3 行只显示序号（`0005`）。

> 排版引擎（v1.1 起）：内容整体（二维码 + 文字块）自动在纸张内居中，
> 四周保留边距；二维码尺寸与字号在「设置」中可调，且会被自动限制——
> 字号保证每行完整放下、不超出纸张，二维码不挤占右侧文字、不超出纸张。
> X/Y 偏移在居中之后应用，用于现场微调。

## 4. 功能需求

### 4.1 扫码（FR-SCAN）

- FR-SCAN-1：主界面提供「扫描配件码」入口，调用相机扫描二维码。
- FR-SCAN-2：扫码结果原文即配件编号，显示给用户确认。
- FR-SCAN-3：重复扫码同一配件编号时，弹出选择：
  - 「沿用之前的产品编号」：查找历史中该配件编号最近一次使用的产品编号并复用。
  - 「生成新编号」：按当前序号生成新的产品编号。

### 4.2 产品系列管理（FR-SERIES）

「产品系列」= 产品名称 + 前缀 A/B/C + 该系列自己的序号。App 同一时刻只有一个**当前系列**，首页产品编号由当前系列生成。

- FR-SERIES-1：设置中提供系列列表，每项显示：产品名称（为空时以「前缀拼接」作为显示名）、前缀摘要、该系列当前序号、是否为当前系列。
- FR-SERIES-2：新建系列；可选「复制现有系列」作为模板。
- FR-SERIES-3：编辑系列的产品名称与三段前缀。
- FR-SERIES-4：删除系列。**当前系列不允许删除**，提示用户先切换到其它系列。
  - 有打印历史的系列被删除后，历史记录保留（记录自带所需数据，不依赖系列）。
- FR-SERIES-5：切换当前系列，立即生效，首页产品编号随之变化。
- FR-SERIES-6：序号**按系列各自维护**。新建系列从 `0001` 起；切回已用过的系列**继续其上次序号**，不重置。
- FR-SERIES-7：修改**当前系列**前缀时**不重置序号**；保存前弹出确认框，展示由「新前缀 + 当前序号」拼出的完整产品编号，用户确认后生效。
  - 仅修改产品名称不触发该确认。
  - 修改非当前系列不触发该确认。
- FR-SERIES-8：产品名称非必填；**空名称不算重名**（允许多个空名称）；非空名称不允许重复。
- FR-SERIES-9：三段前缀允许部分留空，但**至少一段非空**。
- FR-SERIES-10：保存系列时做冲突检测——若其「前缀拼接」与其它系列相同（忽略大小写），给出强提示，由用户决定是否继续。
- FR-SERIES-11：前缀不允许包含 `#`、`@`、`!` 与空格（会破坏二维码固定分隔符），保存时校验并提示。

### 4.3 编号生成（FR-CODE）

- FR-CODE-1：前缀 A/B/C 与序号取自当前产品系列；默认系列的默认前缀为 `ADM32672805` / `CTX` / `6O6`。
- FR-CODE-2：系列配置本地持久化，下次启动读取。
- FR-CODE-3：序号默认 4 位、左补零，每个系列各自从 `0001` 起计。
- FR-CODE-4：序号超过 `9999` 时报错并阻止打印，提示用户处理（仅影响该系列）。

### 4.4 序号管理（FR-SERIAL）

- FR-SERIAL-1：序号仅在**打印成功回调之后**才递增（`waitForFinished` 成功）。
- FR-SERIAL-2：打印失败不递增，序号可被下一次成功打印复用。
- FR-SERIAL-3：设置中提供「手动修正序号」入口（作用于当前系列），需二次确认。
- FR-SERIAL-4：跳号警告——**按系列独立判断**：当前系列的待打印序号 ≠ 该系列上次成功打印的序号 + 1 时（无论何种原因），弹警告对话框，提供「继续跳号打印」按钮，由用户决定是否继续。跨系列切换不触发误报。

### 4.5 打印预览与打印（FR-PRINT）

- FR-PRINT-1：常规模式——扫码后生成 `qrContent` 与标签排版，弹出打印预览（PNG），用户点「打印」后才发送打印。
- FR-PRINT-2：预览取消不消耗序号、不写历史。
- FR-PRINT-3：打印前强制检查连接状态；未连接则提示并尝试重连。
- FR-PRINT-4：一次打印任务只打一张标签，打完停在标签间隙（`LabelType.withGaps`）。
- FR-PRINT-5：打印流程：`stopHeartbeat` → `packetIntervalMs=0` → `createPrintTask` → `printInit` → `printPage` → `waitForFinished` → `startHeartbeat`。
- FR-PRINT-6：打印成功后：序号 +1、写入历史（状态成功）。
- FR-PRINT-7：打印失败：写入历史（状态失败），序号不递增，提示用户。

### 4.6 连续模式（FR-CONT）

- FR-CONT-1：设置中提供「连续模式」开关，默认关闭。
- FR-CONT-2：开启后，扫到配件码直接打印，跳过预览确认。
- FR-CONT-3：连续模式中若一次打印失败或断连，暂停连续流程并弹出提示，由用户决定是否继续。

### 4.7 打印历史与重打（FR-HIST）

- FR-HIST-1：用 `sqflite` 持久化打印历史。
- FR-HIST-2：记录字段见第 6 节数据模型。
- FR-HIST-3：历史列表显示：时间、产品编号、配件编号、序号、状态（成功/失败）、是否重打。
- FR-HIST-4：支持对历史记录执行「重打」——复用记录中的原始 `qrContent` 重新打印。
  - 重打**不递增序号**（同一张标签）。
  - 重打会**新增一条带「重打」标记的记录**，并关联原记录。
- FR-HIST-5：列表按**天分组、倒序**（最近的在前）；组头显示日期与当天条数；时间取设备本地时区。
- FR-HIST-6：支持**多选删除**：进入选择模式后勾选多条，批量删除，删除前二次确认。
  - 「全选」只作用于**当前筛选与搜索命中的结果集**，不是整库。
  - 切换筛选或搜索条件时清空已选条目。
- FR-HIST-7：删除采用**软删除**：记录不再出现在列表与统计中，但**仍参与**跳号判断、重复配件码检测与「沿用旧编号」。
- FR-HIST-8：支持筛选：按产品系列、按月份；均为单选 + 「全部」；两者与搜索条件之间为 AND 关系。
  - 筛选按系列 `id` 匹配，不用系列名称（避免删除后重建同名系列导致数据混淆）。
  - 已被删除的系列，其历史仍可通过该系列筛出。
- FR-HIST-9：支持搜索：按**产品编号**（前缀 + 序号）做模糊匹配。
- FR-HIST-10：列表分页 / 懒加载；历史为空、筛选无结果两种空状态分别提示。

### 4.8 打印机连接（FR-CONN）

- FR-CONN-1：记录并持久化上次连接的设备 ID。
- FR-CONN-2：启动时自动连接上次设备，自动重连重试若干次。
- FR-CONN-3：重试仍失败则提示用户，并提供手动扫描/选择设备入口。
- FR-CONN-4：显示当前连接状态（已连接设备名 / 未连接 / 连接中）。
- FR-CONN-5：注册断连回调（`setOnDisconnect`），断连时更新状态并可自动重连。

### 4.9 设置（FR-SET）

- FR-SET-1：产品系列管理（新增 / 编辑 / 删除 / 切换当前系列），见 4.2。
- FR-SET-2：手动修正序号。
- FR-SET-3：连续模式开关。
- FR-SET-4：打印纸尺寸：宽度 / 高度（毫米）+ DPI；预览与打印均按换算后的像素尺寸生成。
- FR-SET-5：标签排版微调：x 偏移、y 偏移、字号、打印浓度（density 1–5）。
- FR-SET-6：设备管理（当前设备 / 重新连接 / 切换设备）。

### 4.10 权限（FR-PERM）

- FR-PERM-1：Android 12+ 运行时申请 `BLUETOOTH_SCAN`、`BLUETOOTH_CONNECT`、`CAMERA`。
- FR-PERM-2：权限被拒绝时给出引导提示，提供跳转系统设置的入口。

## 5. 状态与异常处理

| 场景 | 处理 |
| :-- | :-- |
| 打印中途断连 | 历史标失败，序号不递增，提示用户；连续模式暂停 |
| 标签纸用完 | 打印任务返回失败，按打印失败处理并提示 |
| 扫码失败/无法识别 | 提示重新扫描，不进入打印流程 |
| 权限被拒绝 | 引导提示 + 跳转设置 |
| 序号超 9999 | 阻止打印，报错提示（仅当前系列） |
| 序号跳号 | 弹警告，提供「继续跳号打印」按钮 |
| 蓝牙未开启 | 提示开启蓝牙 |
| 删除当前系列 | 拒绝，提示先切换到其它系列 |
| 前缀与其它系列冲突 | 保存时强提示，由用户决定是否继续 |
| 切换系列 | 立即生效，首页编号更新；首页需显眼展示当前系列，避免打错系列 |
| 非空名称重复 | 拒绝保存并提示 |

## 6. 数据模型

### 6.1 设置（shared_preferences）

| Key | 类型 | 默认 | 说明 |
| :-- | :-- | :-- | :-- |
| `seriesList` | JSON | 一个默认系列 | 产品系列列表，见 6.3 |
| `currentSeriesId` | String | 默认系列 id | 当前产品系列 |
| `serialLength` | int | 4 | 序号位数 |
| `continuousMode` | bool | false | 连续模式 |
| `offsetX` / `offsetY` | int | 0 | 排版偏移 |
| `labelWidthMm` / `labelHeightMm` | double | 40 / 20 | 打印纸尺寸（毫米） |
| `labelDpi` | int | 300 | 打印分辨率，连接打印机后自动识别 |
| `fontSize` | double | 30 | 文字字号（以 384×240 为基准，随纸张等比缩放，超限自动缩小） |
| `qrSizeMm` | double | 12 | 二维码边长（毫米），超限自动限制 |
| `density` | int | 12 | 打印浓度 |
| `lastDeviceId` | String | 空 | 上次设备 ID |
| `lastDeviceName` | String | 空 | 上次设备名 |
| `printTaskPreference` | String | `auto` | 打印任务偏好（兼容性设置，立即生效） |

### 6.2 打印历史（sqflite，表 `print_history`）

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | INTEGER PK AUTOINCREMENT | 主键 |
| `createdAt` | INTEGER | 时间戳（毫秒） |
| `productCode` | TEXT | 产品编号 |
| `accessoryCode` | TEXT | 配件编号 |
| `serial` | INTEGER | 序号 |
| `qrContent` | TEXT | 二维码原文 |
| `status` | INTEGER | 0=失败，1=成功 |
| `isReprint` | INTEGER | 是否重打 |
| `originalId` | INTEGER | 重打时关联的原记录 ID |
| `deviceId` | TEXT | 打印设备 ID |
| `seriesId` | TEXT | 该记录所属产品系列 id |
| `seriesName` | TEXT | 该记录所属产品系列名称（冗余存储，供系列删除后展示） |
| `deleted` | INTEGER | 0=正常，1=软删除（不显示，但参与跳号/去重判定） |

### 6.3 产品系列（存于 `seriesList` JSON）

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | String | 唯一标识（删除后重建同名系列也不复用） |
| `name` | String | 产品名称，可为空 |
| `prefixA` / `prefixB` / `prefixC` | String | 三段前缀，允许部分为空 |
| `serialNumber` | int | 该系列自己的当前序号 |
| `createdAt` | int | 创建时间戳（毫秒） |

## 7. 非功能需求

- 全程离线运行，不依赖网络。
- 单设备（一台手机）使用，序号与历史存本地。
- 界面语言：简体中文。
- 换手机时提示用户「序号与历史不会自动迁移」，导入/导出后续版本再做。
- 老版本升级：用现有 `prefixA/B/C + serialNumber` 自动生成一个默认系列，序号沿用当前值，不丢数据。

## 8. 待确认与假设

1. **`#MDE:`** 中的 `MDE` 按固定常量处理。
2. **序号上限** 9999，触发后仅报错，不做自动进位。
3. **重复配件码判定** 依据历史中（含软删除）是否存在相同 `accessoryCode`。
4. **重打不占新号**，仅新增带标记的历史记录。
5. 时间显示使用设备本地时间。
6. **前缀字符校验（FR-SERIES-11）** 与**空前缀的行显示规则**为本次新增的推导规则，待确认。
7. 前缀**不自动转换大小写**，保持用户输入；仅冲突检测时忽略大小写比较。
